XED BRANDS — COMBINED WEBSITE UPDATE
====================================

This package combines the premium multi-page XED Brands website and logo update
with the four product preview images and interactive gallery from the second
website package.

WHAT IS INCLUDED
- Premium multi-page website: Home, About Us, Our Brands, Coming Soon, Updates,
  and Contact Us.
- Updated/cropped XED Brands logo and original premium black, red and gold theme.
- Coming Soon page now includes an interactive product slideshow and image gallery:
  farm produce, beverages, snacks, and spices/value-added products.
- Responsive gallery styling and slideshow controls.
- CNAME file for xedbrands.com.
- Original backup-single-page folder retained as a backup only.

PUBLISHING
1. Back up the current GitHub repository first.
2. Extract this ZIP.
3. Upload the CONTENTS of this folder to the ROOT of the existing GitHub Pages
   repository, preserving the assets folder and all HTML pages.
4. Replace existing files when prompted; retain CNAME at repository root.
5. Commit to the main branch and confirm GitHub Pages publishes from main / (root).
6. Preview the site on desktop and mobile before announcing it.

IMPORTANT
- Do not upload this ZIP file itself to GitHub.
- Do not upload backup-single-page over the live root index.html.
- Do not change Namecheap DNS or remove email MX/TXT records if the domain and
  email are already working.
- Check all public contact details and location wording before publishing.
- This Christmas Visual Update adds a prominent festive greeting banner and visible
  animated snowfall to all six pages. Existing product advertisements and images
  remain unchanged. See CHRISTMAS-VISUAL-UPDATE.txt for details.
